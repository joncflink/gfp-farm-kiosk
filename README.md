# GFP Farm Kiosk / Kiosco de Granja

**Global Food Providers** — Daily farm work kiosk for Chiriquí, Panama.

## How to open
- Open `index.html` in any browser, or
- Enable GitHub Pages (Settings → Pages → Deploy from main branch)

## Features
- ¡PLANTA HOY! urgency banner (Spanish first)
- Live weather for Boquete / Chiriquí
- Planting tasks & other work
- Impact counter, weekly goals, staff on duty
- Photo of the day (rainbow over Chiriquí)
- Faith quote of the day

Press **E** to edit. **F11** for fullscreen.
